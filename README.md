One line, under 280 characters: the breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch.

## The line

> It's not you, it's the firmware update. I need someone who doesn't unplug me mid-toast and call it a lifestyle choice.

118 characters. The twist is the lifestyle choice: being unplugged mid-toast is not a quirk to romanticize, it is the reason the toaster is leaving.

## Run it

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), prints it, and reads it back to verify it matches byte for byte.
